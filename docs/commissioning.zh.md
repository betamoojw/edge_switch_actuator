# 调试与验收

以下是**待执行程序，不是测试结果**。须取得现场负责人明确授权，安排维护窗口并准备隔离夹具。本次文档检查保持只读。

记录板卡版本、固件 SHA-256、电源、夹具、仪器、软件版本、初始配置和恢复目标。输出、复位、升级或断网测试前，由合格安装人员隔离实际负载并规定停止条件。

| 项目 | 授权后执行 | 所需证据 |
| --- | --- | --- |
| 单路与脉冲 | 各通道独立执行 ON、OFF 和一次已配置脉冲 | 画面与 COM/NO/NC 测量、脉冲时序；恢复约定状态 |
| 启动 | 记录策略，在批准的上电、复位、升级重启中采集输出 | 初始电气波形和最终状态；软件默认值不够 |
| 权限 | 使用 Viewer/Operator/Installer 和受限通道账号测试批准的允许及拒绝操作 | 被拒操作不改变任何相关输出，含批量预检 |
| 指示与按键 | 记录绑定，测试有界 RGB/提示音及各短按组合 | 优先级、边界、动作和目标正确；普通手势测试不长按 |
| Modbus | 选择批准的总线，执行其验收计划并恢复原模式 | 读取、原子写、异常、掩码、物理输出及传输时序 |
| KNX | 协调地址和所有权，配置后读回，受控测试 Switch/Block/Status | 组对象行为与接点测量；ETS 导入和下载单独验收 |
| HA/MCP | 使用批准的账号与端点，先读再操作一个通道，测试重连 | 发现、就绪、权限、状态传播，重连不重放命令 |
| 断连策略 | 记录配置，按条件中断上行网络或 RTU 轮询 | 实测超时；MQTT/MCP 断连本身不会增加关闭策略 |
| OTA 与持久化 | 确认镜像、私下备份设置，在可本地恢复的条件下手动升级 | 版本、镜像身份、配置保存、协议恢复和输出行为 |
| 破坏性恢复 | 仅指定测试机，另行批准复位和中断写入测试 | 擦除/恢复符合设计，设置身份保留，证据安全保存 |

详细程序见 [TCP](modbus-tcp-relay-fat-sat.md)、[RTU](modbus-rtu-relay-fat-sat.md) 及[历史验证计划](MODBUS_VERIFICATION_VALIDATION_PLAN.md)。出现意外切换、发热、复位、失控或触点测量不一致时立即停止。恢复原配置，确认安全状态后才能交还使用。

功能验收不代表电气认证、负载降额、EMC、安全完整性或 KNX 认证；这些需要独立要求、设备、记录和合格评估。
