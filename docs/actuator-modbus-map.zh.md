# Modbus 接口契约，第 1 版

共享 PDU 引擎和板型适配器已实现本映射。RTU 是 RS485 从站/服务器，TCP 是所选上行网络上的服务器；二者只能择一，且不与 KNX 同时运行。硬件限制见[实现记录](actuator-implementation.md)。

## 功能码与编码 { #functions-and-encoding }

支持 FC01/02/03/04 读取线圈、离散输入、保持/输入寄存器，FC05/06 单写，FC15 (`0x0F`)/16 (`0x10`) 多写，FC43/14 (`0x2B/0x0E`) 设备识别。FC08 仅 RTU，支持子功能 0 回显。其他功能/子功能返回异常 01；第 1 版不要求 FC22/23。

表中均为四个独立地址空间的**十六进制零基 PDU 偏移**，不是 00001/40001 显示编号。线圈低位先打包；寄存器网络字节序；32 位值高字在前，读取为原子快照；布尔值 0/1。未知或保留地址返回 02。

FC05 只接受 `0x0000` OFF、`0xFF00` ON，不支持 `0x5500`。多写在修改前检查整笔地址、数值、启用、锁定及权限，跨空洞失败。非法值返回 03，不可访问/锁定返回 02，内部失败 04，队列或切换忙 06；CRC 错误或其他站号静默丢弃。

FC43 基本对象：00 厂商、01 产品码 `EDGE-S3-6CH`、02 固件版本；支持基本流读取码 01 和分页，其他读取码返回 03。只读对象放在 DI/IR。规范参考 [Modbus 官方资料](https://www.modbus.org/modbus-specifications)、[串行指南](https://www.modbus.org/file/secure/modbusoverserial.pdf)、[TCP 指南](https://www.modbus.org/file/secure/messagingimplementationguide.pdf)。

## 线圈：FC01 / FC05 / FC15 { #coils-fc01-fc05-fc15 }

| 偏移 | 含义 | 访问 |
| --- | --- | --- |
| 0x0000–0x0005 | CH1–CH6 稳态 ON/OFF，读回已应用命令状态 | 启用、未锁定且掩码允许时运行写入 |
| 0x0010–0x0015 | CH1–CH6 启用 | 暂存配置，需调试窗口 |
| 0x0020 / 0x0021 | RGB / 蜂鸣器启用 | 暂存配置 |
| 0x0022 | 应用按键动作启用 | 暂存配置，保留长按复位 |
| 0x0023 | 保留、未映射 | RS485 状态只从 DI 0x0023 读 |
| 0x0030 | 手动 RGB 请求 | 须启用 RGB，高优先级指示可覆盖 |
| 0x0031 | 手动蜂鸣请求 | 须启用蜂鸣器，受时间限制 |

手动控制仅在 ON 上升沿启动，OFF 取消，到期清零；重复 ON 不延长时间。普通继电器写取消脉冲。未提供 Modbus 复位或协议切换命令；RS485 启用只允许网页修改，UART 参数仍可读取。

## 离散输入：FC02 { #discrete-inputs-fc02 }

| 偏移 | 含义 |
| --- | --- |
| 0x0000–0x0005 | 已应用输出，非触点反馈 |
| 0x0010 / 0x0011 | 消抖后的 BOOT 按下 / 应用按键启用 |
| 0x0012 / 0x0013 | RGB 当前非黑 / 蜂鸣器发声 |
| 0x0014 / 0x0015 | 上行可用 IPv4 / AP 活动 |
| 0x0016 / 0x0017 | 存在故障 / KNX 编程（Modbus 活动时恒假） |
| 0x0020 / 0x0021 | RGB / 蜂鸣器启用 |
| 0x0022 / 0x0023 | 按键服务可用 / RS485 启用 |
| 0x0024 / 0x0025 / 0x0026 | RS485 初始化 / Modbus 就绪 / 配置窗口打开 |
| 0x0030–0x0035 | 通道锁定 |

## 保持寄存器：FC03 / FC06 / FC16 { #holding-registers-fc03-fc06-fc16 }

| 偏移 | 字段 | 范围及默认 |
| --- | --- | --- |
| 0x0100 / 0x0101 / 0x0102 | 手动 RGB 红/绿/蓝 | 0–255，默认 0 |
| 0x0103 | 手动亮度 | 0–100%，默认 10 |
| 0x0104 | RGB 时长 | 1–30 秒，默认 5 |
| 0x0110 | 蜂鸣器频率 | 500–4000 Hz，默认 2000；物理适用范围待验证 |
| 0x0111 / 0x0112 | 蜂鸣时长 / 占空比 | 10–2000 ms/1–50%，默认 100/25 |
| 0x0120 / 0x0121 | 单击动作 / 目标 | 暂存；动作见下方，目标 0 全部启用通道或设备，1–6 单路 |
| 0x0122–0x0123 / 0x0124–0x0125 | 双击 / 三击动作与目标 | 同上 |
| 0x0130–0x0135 | 启动状态 | 0 OFF / 1 ON，暂存 |
| 0x0140–0x0145 | 脉冲时长 | 10–60000 ms，默认 1000，暂存 |
| 0x0150–0x0155 | 断连策略 | 0 保持 / 1 OFF，默认保持，暂存 |
| 0x0160–0x0165 | 断连超时 | 1–3600 秒，默认 30，暂存 |
| 0x0200 | 命令码 | 0 空闲、1 识别、2 确认告警、3 脉冲、4 应用暂存、5 丢弃暂存 |
| 0x0201 | 命令目标 | 脉冲 0 为全部启用通道，其他为设备；1–6 单路 |
| 0x0202 | 请求序号 | 1–65535，每命令递增 |
| 0x0203 | 提交触发 | 写 0xA55A；读为 0，写 0 无动作 |

动作枚举：0 无、1 ON、2 OFF、3 切换、4 脉冲、5 全关、6 识别、7 确认、8 KNX 编程切换（只在 KNX 模式执行）。应用配置时校验动作/目标配对。RGB/蜂鸣参数只在 RAM，下一次触发生效，不能压制故障或编程指示。

按键目标 0 对启用通道逐路执行，跳过锁定/禁用；指定通道必须启用。Modbus 全部脉冲要求所有启用通道均有权限且未锁定，否则整体拒绝；网页 `all_on`/`all_off` 同样预检。

命令邮箱必须用**一笔 FC16** 写满 `0x0200–0x0203`，拒绝这些地址的 FC06。四字一起锁存、验证和执行，结果在 IR。每 TCP 会话或 RTU 总线会话按序号和负载去重；同负载重试返回旧结果，同序号不同负载失败。缓存最多 16 条、60 秒，期间不重用序号；重启会清空，重试脉冲前检查 uptime。应用/丢弃暂存仅在授权窗口允许。

| 0x0001 | 能力位 0–4：继电器/RGB/按键/蜂鸣器/RS485；5–7：RTU/TCP/KNX 编译支持 |
| 0x0002 | 协议 0 OFF、1 RTU、2 TCP、3 KNX |
| 0x0003 | 网络 0 离线、1 仅 AP、2 STA 连接中、3 上行 IPv4、4 上行 IPv4+AP |
| 0x0004 / 0x0005 | 主故障码 / 手势：0 无、1 单击、2 双击、3 三击、4 复位长按 |
| 0x0006–0x0007 / 0x0008–0x0009 | 手势序号 / 运行秒数 |
| 0x000A–0x000B | 已应用配置修订 |
| 0x0010–0x0011 / 0x0012–0x0013 / 0x0014–0x0015 | 有效请求 / CRC或帧错误 / 拒绝写计数 |
| 0x0020 | RTU 站号 |
| 0x0021 | 波特率：0=9600、1=19200、2=38400、3=57600、4=115200 |
| 0x0022 | 格式：0=8E1、1=8O1、2=8N2、3=8N1 兼容 |
| 0x0023 / 0x0024 | TCP 端口 / 客户端数 |

| 0x0030 / 0x0031 / 0x0032 | 当前红/绿/蓝，0–255 |

不提供伪造物理按键状态的注入接口。计数按 `2^32` 回绕，多寄存器读取内部一致。

## 配置权限及传输参数 { #configuration-access-and-transport-profiles }

默认只允许配置掩码内启用通道的继电器写。手动指示、脉冲/确认、配置各有安装人员设置的权限。网页安装人员可为指定 TCP 对端/会话或受控 RTU 总线打开默认 60 秒、最长 300 秒的窗口；RTU 窗口对总线上所有主站开放，无法逐一认证。

暂存只在 RAM，窗口所有者读到暂存值，其他客户端读有效值。打开时记录配置修订，应用前校验完整候选和修订，再持久提交；并发网页修改会冲突且不改有效状态。关闭/到期丢弃未提交数据。UART、网络、板型、访问策略及协议族只能网页修改，避免响应链路在配置时消失。

RTU：RS485 必须启用，站号 1–247（默认 1），默认 19200/8E1，可选 8O1/8N2/8N1 兼容。UART 空闲事件划帧，尚不能严格拒绝缓冲帧内所有超过 1.5 字符的间隔。ADU 最长 256 字节，各波特率的自动转向须实测。站号 0 仅接受六路继电器范围内有效 FC05/15 广播且不响应；忽略广播读取/配置。不另开主站轮询服务。

TCP：默认端口 502、unit 1、最多四客户端、空闲 60 秒、可限制单一 IPv4。绑定所选上行，默认不暴露于配网 AP。验证 MBAP 协议、事务、长度和 unit，支持分片/拼接，ADU 最长 260 字节，错误流有界处理后关闭。错误 unit 返回 `0x0B`，unit 0 不是广播；不支持 RTU-over-TCP，也不含 CRC。

两者共用 `src/protocols/ModbusPdu.h`，原生测试含 FC43/14、FC08；真实主站互操作仍需验证。

## 所需互操作测试 { #required-interoperability-tests }

RTU/TCP 均应验证读取边界、FC05 合法值、FC06 范围、FC15/16 原子拒绝、空洞、FC43 身份、FC08 回显、广播静默、CRC 错误、字符延迟、多客户端及超时命令。拒绝写不得改变禁用硬件、安全设置、UART 或执行复位；暂存不得在 Apply 前写闪存，提交中断恢复须另测。
