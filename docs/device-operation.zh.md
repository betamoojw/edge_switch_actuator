# 设备操作

浏览器入口为 `/device`，包含 Outputs、Indicators、Button、Protocol Interface、KNX 和 Maintenance。可用控件取决于当前账号权限及编译功能。真实画面见[界面导览](interface-tour.md)，连接步骤见[首次使用](quick-start.md)。

## 输出 { #outputs }

界面通道编号为 **1–6**。每路可设置启用、启动状态、名称、脉冲时长及断连关闭超时。禁用通道会被强制关闭；锁定通道拒绝普通继电器命令，安装人员或管理员可解锁。脉冲使用保存的时长，到期强制 OFF；之后接受的普通继电器命令会取消计时。

网页批量 ON/OFF 会先检查所有启用通道；只要有一路锁定或缺少权限，整个请求就会被拒绝。禁用通道保持 OFF。状态与事件快照反映的是命令状态，不是触点测量值。

默认启动状态为 OFF。选择启动 ON 会改变重启后的行为。KNX 调试完成后，应在 KNX 区域修改继电器参数。版本冲突时重新加载并合并修改。通道旁的 `startup` 只是最后命令来源，启动行为应以保存的配置为准。

## 协议选择 { #protocol-selection }

| 模式 | 条件及行为 |
| --- | --- |
| Off | 停止现场总线，网页及已启用的 MQTT/MCP 仍可工作 |
| Modbus RTU | 启用 RS485；默认站号 1、19200 baud、8E1 |
| Modbus TCP | 所选上行接口具有 IPv4；默认端口 502，可限制为一个精确 IPv4 对端 |
| KNX/IP | 所选上行接口具有 IPv4；需配置个体地址、组地址和参数 |

同时只运行一种总线。`waiting_network` 表示等待上行网络，不等于保存失败；仅连接配网 AP 不满足要求。参见 [Modbus](actuator-modbus-map.md) 和 [KNX](knx-address-entry.md)。

断连关闭默认禁用。TCP/KNX 依据所选上行接口断开后的超时，而非某个主站或报文流消失；RTU 需要启用总线看门狗，以总线无活动时间判断。仅 MQTT/MCP 断开不会自动关闭输出。

## 按键和指示器 { #button-and-indicators }

单击、双击、三击均可绑定，默认分别为无动作、识别、切换 KNX 编程模式。继电器目标 0 表示全部启用通道，1–6 为指定通道。本地按键会跳过锁定或禁用通道。禁用应用按键动作不会取消恢复出厂设置长按。

消抖为 30 ms；短按最长 700 ms；释放间隔 350 ms 后判定组合。长按 5 秒进入复位预备状态，10 秒执行恢复出厂。开机时已按住的按钮必须先释放。

RGB 优先级依次为：复位预备、故障、KNX 编程、手动识别或测试、上行已连接、AP 配网、等待或连接中；须先启用 RGB。手动测试为 1–30 秒。蜂鸣器须启用，范围为 500–4000 Hz、10–2000 ms、1–50% 占空比。确认提示音只会静音，不会清除故障。

## 角色权限 { #access-roles }

| 角色 | 执行器权限 |
| --- | --- |
| Viewer | 认证后读取状态与配置 |
| Operator | 运行命令；继电器写入受通道掩码限制 |
| Installer | 运行命令、配置、协议及 KNX 调试、解锁、Modbus 写入窗口 |
| Administrator（`admin` 标志） | 全部通道，以及用户、网络、集成管理、复位与更新 |

通道掩码不是整个框架的通用授权模型；框架设置通常要求管理员。MQTT 由代理 ACL 控制，MCP 使用独立的开放通道掩码，两者都不继承浏览器账号的掩码。

## 维护与故障解释 { #maintenance-and-fault-interpretation }

在 **System → Firmware Update** 手动上传匹配的 `_ota.bin`，参见[更新说明](buildprocess.md)。当前板型禁用深度睡眠。

| 故障码 | 源码含义 |
| --- | --- |
| 0 | 未记录活动故障 |
| 1 | 蜂鸣器 PWM 分配失败 |
| 2 | 保存的执行器配置无效，已载入默认值 |
| 3 | 协议初始化失败 |
| 4 | 恢复出厂标记或清理失败 |
| 5 | KNX 持久化失败，重试成功后清除 |
| 6 | KNX 应用参数无效 |

结合 `error`、协议状态和内存审计日志判断。恢复出厂会清除可重置配置和 KNX 调试数据，但保留制造时生成的设置密码。如需清除 Home Assistant 保留的发现信息，应在代理可达时先禁用发现，再移除或复位设备，见[生命周期](home-assistant.md)。
