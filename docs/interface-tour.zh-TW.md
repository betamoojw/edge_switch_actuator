# 介面導覽

以下截圖來自 Waveshare 實機的**英文介面**，於 **2026 年 10 月 10 日**以唯讀方式擷取。畫面顯示韌體 **0.6.3**，確切提交未知，設定也不一定是原廠值。本次未操作繼電器、指示功能、組態、重設或更新。圖下編號用來說明控制項，未更動裝置畫面；裁切範圍已排除網路識別資訊與認證資料。可開啟原圖查看。[檢查紀錄](live-verification.md)另行區分觀察與原始碼推導。

## 1. 輸出 { #1-outputs }

![六個通道皆為 OFF，可見 Turn ON、Pulse、收合設定與全部控制。](media/live/outputs.jpg)

1. **通道與 OFF：** 通道編號 1–6，檢查時皆為 OFF；這不是接點回授。
2. **Enabled · startup：** 通道已啟用，最後命令來自啟動流程；開機策略需另外查看。
3. **Turn ON / Pulse：** 授權操作員可送出命令，脈衝到期強制 OFF；本次未按下控制項。
4. **設定與全部操作：** 安裝人員/管理員的組態權限與操作權限不同。任一啟用通道遭鎖定或權限不足時，整筆網頁批次命令會被拒絕，詳見[角色](device-operation.md#access-roles)。

## 2. 指示功能 { #2-indicators }

![RGB 已啟用，亮度為 25%，目前呈綠色數值，蜂鳴器停用。](media/live/indicators.jpg)

1. **RGB：** 此機回報綠色 `(0, 63, 0)`、亮度 25%，原始碼預設則為 10%。
2. **Test color / Identify：** 會執行實體動作；故障、重設及程式設定等高優先序狀態可能蓋過手動測試。
3. **蜂鳴器：** Enabled 未勾選，頻率為 0 Hz，測試按鈕停用；未實際驗證聲音或燈光。

## 3. 按鍵 { #3-button }

![單擊為 KNX 程式設定、雙擊識別、三擊全通道脈衝，另有十秒重設提醒。](media/live/button.jpg)

1. **Released / 事件次數：** 軟體回報按鍵已放開，擷取時沒有辨識到事件。
2. **動作指派：** 此機單擊進入程式設定、雙擊識別、三擊全通道脈衝；預設其實是無動作、識別、程式設定切換。按 BOOT 前務必核對。
3. **長按：** 十秒將清除設定及試運轉資料，即使應用點擊功能停用仍有效。已安裝裝置若無復原計畫，請勿測試。

## 4. 通訊存取 { #4-protocol-access }

![通訊設定下方顯示寫入遮罩 63、指示命令停用、計數器為零且設定時窗關閉。](media/live/protocol-access.jpg)

1. **遮罩 63：** 位元 0–5 允許 Modbus 寫入六路，與網頁帳號及 MCP 權限分開。
2. **手動指示及診斷：** 此機未啟用。
3. **計數器與時窗：** 零計數不能證明連線正常，尤其目前使用 KNX。開啟時窗會暫時授予設定權限，本次未開啟。RTU 無法個別認證 RS485 主站。

裁切範圍之外的選單為 **KNXnet/IP**。RTU/TCP 尚未作用時仍可能顯示設定，但一次只有一種現場總線運作。

## 5. KNX 設定 { #5-knx-commissioning }

![KNX 顯示應用已設定、Programming OFF、擁有者 web、修訂 2、個別位址 1.2.1。](media/live/knx.jpg)

1. **已設定 / Programming OFF：** 僅為軟體狀態，不代表 ETS 驗收或實體電文測試通過。
2. **擁有者與修訂：** 畫面為 web、修訂 2。KNX 有獨立修訂號，衝突時須重新讀取。
3. **位址：** `1.2.1` 是此機的保存範例，現場應依拓撲指派唯一位址；原廠提示為 `15.15.255`。

畫面的三擊說明假設使用預設綁定，與此機的單擊指派不同。請以[按鍵設定](#3-button)及 [KNX 指南](knx-address-entry.md)為準。開發識別警告並不代表 KNX 認證。[ETS 與網頁擁有權範例](knx-address-entry.md#ets-download-and-web-ownership-screenshot-walkthrough)是另一組使用者提供的圖片。

## 6. 維護 { #6-maintenance }

![維護頁有設定修訂號，原廠重設確認欄空白，清除按鈕停用。](media/live/maintenance.jpg)

1. **修訂與運作時間：** 適合提供報修背景，不是耐久驗證。
2. **清除確認：** 屬破壞性復原，不是儲存或登出；本次未填寫也未執行。
3. **近期活動：** 儲存在記憶體中，並非永久稽核檔案。

## 7. 系統狀態及導覽 { #7-system-status-and-navigation }

![系統狀態列出記憶體、檔案系統、溫度、重設原因、韌體 0.6.3 與 ESP32-S3。](media/live/system-status.jpg)

1. **韌體、晶片與 SDK：** 尋求支援時請記錄，並盡量提供映像檔雜湊；版本字串不能唯一識別編譯功能。
2. **記憶體、檔案系統及溫度：** 只是當下遙測，無法證明熱管理或堆積記憶體驗證完成。
3. **系統選單：** 偏好設定、狀態、指標、核心傾印與更新分屬不同頁面。更新必須使用相符 `_ota.bin`，見[映像檔選擇](buildprocess.md#firmware-build-and-release-artifacts)。

檢查時 Connections 有 MQTT、NTP，未見小智 MCP，MQTT 為 Disabled。因此 HA/MCP 指南依目前原始碼撰寫，不是此機的完整整合測試結果。
