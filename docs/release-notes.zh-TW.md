# 目前版本與文件基準

審查日期為 **2026 年 10 月 11 日**，`dev` 提交為 [`bf8cb12`](https://github.com/betamoojw/edge_switch_actuator/tree/bf8cb12ab9ada4337751968332c7d5e17e056ccc)。`platformio.ini` 的 `APP_VERSION` 已設定為 **0.6.4**。以下依原始碼說明變更，不表示現場裝置已更新至此版本。

## 韌體 0.6.4 { #firmware-064 }

- GitHub 儲存庫識別值改為 `betamoojw/edge_switch_actuator`；移除 `/tree/dev`，修正更新介面組成的發行版本 API 網址。
- 側邊欄以 **Project website** 取代 Discord 連結，導向這個 GitHub Pages 文件網站。
- 已重新產生內嵌介面及儲存庫中的預設板型韌體。檔案用途見[映像檔選擇](buildprocess.md#firmware-build-and-release-artifacts)。
- 版本管理新增 `buildRelease/Edge_S3_Relay_6CH.knxprod`。這不等於完成 ETS 驗收或取得 KNX 認證；一般韌體封裝掛鉤也不會自動產生此套件。

相較於先前文件基準 `ced3e6d`，後端 REST 路由、繼電器策略、持久化設定格式，以及 Modbus、KNX、MQTT、MCP 行為皆無異動。

## 仍待處理的限制與證據 { #remaining-limits-and-evidence }

發行版本選擇器仍以 `.bin` 與板型名稱子字串比對，可能納入合併映像檔或近似板型。請手動選用完全相符的 `_ota.bin`。網址修正不能證明檔案挑選安全，也不能當作實機更新成功的依據。

`media/live/` 是 **2026 年 10 月 10 日擷取的 0.6.3 英文介面**，側邊欄與 0.6.4 已不同。使用者提供的 KNX 截圖尚未確認韌體版本。本次文件更新未操作繼電器或指示燈，也未重新啟動、重設、更新韌體或變更設定。

[目前原始碼審查](actuator-source-review.md)列出未解決事項；[既有驗證紀錄](validation.md)保留原始日期與結果，不代表重新驗證過 0.6.4。

## 文件驗證：2026 年 10 月 11 日 { #documentation-validation }

**32 篇現行指南**均提供英文、簡體中文與繁體中文，共 96 個語言頁面。歷史資料保留原文並清楚標示。兩種中文版本已審閱地區用語及技術含義；這是代理程式的審閱，並非獨立人工翻譯認證。

- 嚴格 MkDocs 建置通過。離線檢查涵蓋 166 個 HTML 頁面的現行譯文、內部連結與錨點、圖片替代文字、語言選擇器及搜尋索引內容。
- 瀏覽器以 1440 × 1000 和 390 × 844 視窗檢查桌面/行動排版、導覽、對應頁切換、在地化圖表與圖片。搜尋 `relay`、`继电器`、`繼電器` 都有結果。搜尋共用多語索引，技術詞彙可能同時符合多種語言版本。
- 已檢視既有裝置及 KNX 截圖的隱私資訊，並遮蔽 KNX 圖片中的私人端點。文字範例採文件預留值，原廠 AP 位址則保留實際預設值。
- 本次未建立新的裝置工作階段，未執行繼電器測試、ETS 下載、韌體編譯、OTA 更新或硬體資格驗證。0.6.3 截圖與版本未確認的 KNX 圖片仍受各自證據範圍限制。

Pages 工作流程會在部署前重新執行嚴格建置及離線檢查。各語言目錄的 `build-info.json` 可識別已部署的文件提交。
