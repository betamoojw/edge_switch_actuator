# 試運轉與驗收

以下是**尚待執行的程序，不是已完成結果**。須取得現場負責人明確授權，安排維護時段並準備隔離治具。本次文件檢查僅做唯讀操作。

請記錄板卡版本、韌體 SHA-256、電源、治具、儀器、軟體版本、起始組態及復原目標。進行輸出、重設、更新或斷網測試前，由合格安裝人員隔離現場負載並訂好停止條件。

| 項目 | 核准後的程序 | 應留存證據 |
| --- | --- | --- |
| 單路與脈衝 | 各路分別操作 ON、OFF 及一次設定脈衝 | 畫面、COM/NO/NC 量測與脈衝時序；恢復約定狀態 |
| 開機 | 記錄策略，於核准的上電、重設及更新重啟中擷取輸出 | 初始電氣波形及最終狀態，不能只看軟體預設值 |
| 權限 | 以 Viewer/Operator/Installer 及受限通道帳號執行允許與拒絕案例 | 拒絕操作不改變相關輸出，含全部操作的預先檢查 |
| 指示與按鍵 | 記錄指派，測試有限時間 RGB、提示音及短按組合 | 優先序、限制、動作與目標正確；一般手勢測試不長按 |
| Modbus | 切至核准傳輸方式，完成驗收再復原 | 讀取、原子寫入、例外、遮罩、接點動作與時序 |
| KNX | 協調位址與擁有權，設定並讀回，再受控測試 Switch/Block/Status | 群組行為及接點量測；ETS 匯入與下載另行驗收 |
| HA/MCP | 使用核准帳號與端點，先讀取再操作單一路，測試重新連線 | 探索、就緒、權限、狀態傳播，重連不重送舊命令 |
| 斷線策略 | 記錄組態，再中斷選定上行或 RTU 輪詢 | 實測逾時；MQTT/MCP 斷線本身不新增關閉策略 |
| OTA 與持久化 | 核對映像檔、私下備存設定，準備本機復原後手動更新 | 版本與映像識別、設定保留、通訊恢復及輸出行為 |
| 破壞性復原 | 僅使用指定測試機，重設及寫入中斷須另行核准 | 清除/復原符合設計、設定身份保留，證據妥善保管 |

細節見 [TCP](modbus-tcp-relay-fat-sat.md)、[RTU](modbus-rtu-relay-fat-sat.md) 及[歷史驗證計畫](MODBUS_VERIFICATION_VALIDATION_PLAN.md)。發生非預期切換、發熱、重啟、失控或接點量測不一致時，立即停止。復原組態並確認安全狀態後，才可交回現場。

功能測試通過並不代表電氣認證、負載降額、EMC、安全完整性或 KNX 認證；這些需要另訂要求、使用適當設備、留存紀錄並由合格人員評估。
