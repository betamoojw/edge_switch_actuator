# Modbus 介面契約，第 1 版

本映射由共用 PDU 引擎及板型配接層實作。RTU 為 RS485 從站/伺服器，TCP 為選定上行介面的伺服器；兩者擇一，且不能與 KNX 並行。硬體驗證範圍見[實作紀錄](actuator-implementation.md)。

## 功能碼及編碼 { #functions-and-encoding }

支援 FC01/02/03/04 讀取線圈、離散輸入、保持/輸入暫存器，FC05/06 單筆寫入，FC15 (`0x0F`)/16 (`0x10`) 多筆寫入，以及 FC43/14 (`0x2B/0x0E`) 裝置識別。FC08 僅供 RTU，子功能 0 為回送查詢資料。不支援的功能/子功能回傳例外 01，第 1 版不要求 FC22/23。

下列位址皆為四個獨立空間中的**十六進位、從零起算的 PDU 偏移**，不是 00001/40001 顯示編號。線圈從最低位元封裝；暫存器採網路位元組順序；32 位元數值先高字，並以原子快照讀取。布林值為 0/1，保留或未知位址回傳 02。

FC05 僅接受 `0x0000` OFF 與 `0xFF00` ON，禁止 `0x5500`。多筆寫入先驗證全部位址、值、啟用、鎖定及權限，跨越未映射區域會失敗。無效值為 03，不可存取/鎖定為 02，內部失敗為 04，佇列或切換忙碌為 06；CRC 錯誤或其他站號直接丟棄。

FC43 基本物件 00 為廠商、01 為 `EDGE-S3-6CH`、02 為韌體版本。支援基本串流讀取碼 01 及分頁，其他讀取碼回傳 03。唯讀項目放在 DI/IR。規範見 [Modbus 官方文件](https://www.modbus.org/modbus-specifications)、[序列指南](https://www.modbus.org/file/secure/modbusoverserial.pdf)、[TCP 指南](https://www.modbus.org/file/secure/messagingimplementationguide.pdf)。

## 線圈：FC01 / FC05 / FC15 { #coils-fc01-fc05-fc15 }

| 偏移 | 定義 | 存取方式 |
| --- | --- | --- |
| 0x0000–0x0005 | CH1–CH6 穩態 ON/OFF，讀回已套用命令 | 啟用、未鎖定且通訊遮罩允許才可寫入 |
| 0x0010–0x0015 | CH1–CH6 啟用 | 暫存組態，需設定時窗 |
| 0x0020 / 0x0021 | RGB / 蜂鳴器啟用 | 暫存組態 |
| 0x0022 | 應用按鍵動作啟用 | 暫存組態，不影響保留的長按重設 |
| 0x0023 | 保留，未映射 | RS485 狀態只可由 DI 0x0023 讀取 |
| 0x0030 | 手動 RGB 請求 | RGB 須啟用，較高優先序可覆蓋 |
| 0x0031 | 手動蜂鳴請求 | 蜂鳴器須啟用，且有時間上限 |

手動控制在 ON 上升緣啟動一次，OFF 取消，到期自動清除線圈；重複 ON 不延長期限。一般繼電器寫入取消該路脈衝。沒有 Modbus 原廠重設或協定切換命令。RS485 啟用僅能從網頁變更，UART 參數仍可讀取。

## 保持暫存器：FC03 / FC06 / FC16 { #holding-registers-fc03-fc06-fc16 }

| 偏移 | 欄位 | 範圍及預設值 |
| --- | --- | --- |
| 0x0100 / 0x0101 / 0x0102 | 手動 RGB 紅/綠/藍 | 0–255，預設 0 |
| 0x0103 | 手動亮度 | 0–100%，預設 10 |
| 0x0104 | RGB 時間 | 1–30 秒，預設 5 |
| 0x0110 | 蜂鳴器頻率 | 500–4000 Hz，預設 2000，實際適用範圍仍需驗證 |
| 0x0111 / 0x0112 | 發聲時間 / 工作週期 | 10–2000 ms / 1–50%，預設 100/25 |
| 0x0120 / 0x0121 | 單擊動作 / 目標 | 暫存，動作見下文；0 為全部啟用通道或裝置，1–6 單一路 |
| 0x0122–0x0123 / 0x0124–0x0125 | 雙擊 / 三擊的動作與目標 | 格式相同 |
| 0x0130–0x0135 | 開機狀態 | 0 OFF / 1 ON，暫存 |
| 0x0140–0x0145 | 脈衝時間 | 10–60000 ms，預設 1000，暫存 |
| 0x0150–0x0155 | 斷線策略 | 0 保持 / 1 OFF，預設保持，暫存 |
| 0x0160–0x0165 | 斷線逾時 | 1–3600 秒，預設 30，暫存 |
| 0x0200 | 命令碼 | 0 閒置、1 識別、2 確認警報、3 脈衝、4 套用暫存、5 放棄暫存 |
| 0x0201 | 目標 | 脈衝 0 為全部啟用通道，其他命令為裝置；1–6 指定繼電器 |
| 0x0202 | 請求序號 | 1–65535，每次命令遞增 |
| 0x0203 | 提交觸發 | 寫入 0xA55A，讀回 0；寫 0 無動作 |

動作列舉：0 無、1 ON、2 OFF、3 切換、4 脈衝、5 全關、6 識別、7 確認、8 KNX 程式設定切換（僅 KNX 模式執行）。套用時驗證動作與目標組合。RGB/蜂鳴參數只放在 RAM，下一次觸發才生效，不能壓過故障或程式設定指示。

按鍵目標 0 逐路處理已啟用通道，略過停用或鎖定者；單一路目標必須啟用。Modbus 全通道脈衝要求每個啟用通道都有權限且未鎖定，否則整筆拒絕。網頁 `all_on`/`all_off` 也先做完整檢查。

命令信箱必須以**單筆 FC16** 寫入 `0x0200–0x0203` 全四字，這些位址不接受 FC06。一次鎖存、驗證並執行，結果由 IR 取得。每 TCP 工作階段或 RTU 總線階段以序號及內容去重：相同內容回傳既有結果，相同序號不同內容則失敗。保留最多 16 筆、60 秒，期間勿重用序號。重新啟動會清除快取，重試脈衝前須看 uptime；套用/放棄暫存僅限授權時窗。

| 0x0002 | 協定 0 OFF、1 RTU、2 TCP、3 KNX |

| 0x0006–0x0007 / 0x0008–0x0009 | 手勢序號 / 運作秒數 |
| 0x000A–0x000B | 已套用組態修訂 |
| 0x0010–0x0011 / 0x0012–0x0013 / 0x0014–0x0015 | 有效請求 / CRC或訊框錯誤 / 拒絕寫入次數 |

| 0x0023 / 0x0024 | TCP 連接埠 / 用戶端數 |

| 0x0026 | 結果：0 無、1 等待、2 已套用、3 拒絕、4 失敗 |

## 設定權限與傳輸組態 { #configuration-access-and-transport-profiles }

預設僅允許遮罩內已啟用通道的繼電器寫入。手動指示、脈衝/確認及組態寫入各有安裝人員設定的權限。網頁安裝人員可為指定 TCP 對端/工作階段，或受控 RTU 總線，開啟預設 60 秒、最長 300 秒時窗。RTU 無法辨識個別主站，時窗對全總線參與者有效。

暫存只在 RAM，時窗擁有者讀到暫存值，其他用戶端讀到有效設定。建立時記錄基準修訂，套用前驗證完整候選及修訂，再持久提交；並行網頁修改造成衝突時不改變有效狀態。關閉或到期會丟棄未提交內容。UART、網路、板型、存取規則及協定族僅能網頁修改，以免回應連線中途消失。

RTU 須啟用 RS485，站號 1–247（預設 1），預設 19200/8E1，可選 8O1/8N2/8N1 相容。以 UART 閒置事件定界，尚無法嚴格拒絕緩衝訊框內所有超過 1.5 字元的間隔。ADU 上限 256 位元組，各鮑率的自動轉向需量測。站號 0 只接受六路線圈內有效 FC05/15 廣播且不回應；廣播讀取及組態寫入忽略。不另行執行主站輪詢。

TCP 預設埠 502、unit 1、四用戶端、閒置逾時 60 秒，可限單一 IPv4。綁定選定上行，預設不在設定 AP 提供服務。檢查 MBAP 協定、交易、長度及 unit，支援分段與串接，ADU 上限 260 位元組。錯誤串流有界處理後關閉；無效 unit 回傳 `0x0B`，unit 0 不是廣播。不支援 RTU-over-TCP，TCP ADU 沒有 CRC。

兩者共用 `src/protocols/ModbusPdu.h`；原生測試含 FC43/14、FC08，真實主站互通仍待驗證。

## 必要互通測試 { #required-interoperability-tests }

兩種傳輸都要檢查讀取邊界、FC05 合法值、FC06 範圍、FC15/16 全有或全無、保留空洞、FC43 識別、FC08 回送、廣播靜默、CRC 錯誤、字元延遲、競爭用戶端及逾時命令。拒絕的寫入不得更動停用硬體、安全設定、UART 或觸發重設；暫存不能在 Apply 前寫 Flash，提交中斷的復原另須測試。
